**MotionUnityGame** is an interactive Unity-based game that utilizes real-time motion data from a mobile device to control in-game actions. By connecting a smartphone's motion sensors to the Unity engine.

---

## 🎯 Purpose

This project showcases the integration of mobile sensor data with a Unity game, highlighting skills in cross-platform communication, real-time data processing, and interactive game development. It's particularly useful for exploring alternative input methods in gaming and interactive applications. Notably, this application was developed as my engineering thesis project.

---

## ✨ Features

- 📱 **Mobile Motion Control**  
  Leverages smartphone sensors (accelerometer, gyroscope) to influence game mechanics.

- 🔗 **Real-Time Data Integration**  
  Establishes a connection between the mobile device and the Unity game to transmit motion data instantly.

- 🕹️ **Interactive Gameplay**  
  Players can control game elements through physical movements of their mobile devices.

- 🧪 **Experimental Input Methods**  
  Explores non-traditional input for gaming, suitable for research and development in human-computer interaction.

---

## 🛠️ Technologies Used

- **Game Engine**: Unity  
- **Programming Language**: C#  
- **Mobile Integration**: Custom scripts to receive and process motion data from mobile devices  
- **Development Tools**: Visual Studio, Unity Editor

## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) with Unity Editor installed  
- [Visual Studio](https://visualstudio.microsoft.com/) with Unity workload  
- A smartphone capable of transmitting motion sensor data

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arturzelek1/MotionUnityGame.git
   cd MotionUnityGame
2. **Open project in Unity:**
- Launch Unity Hub.
- Click on "Add" and select cloned project folder.
3. **Set up the mobile device:**
- Download and install Android app from my repository to log and send motion data to Unity
- Ensure the mobile device can send motion data to the Unity application.
- Configure the connection settings within the Android application
4. **Run the game:**
- Press the "Play" button in the Unity Editor to start the game
- Move the mobile deivce to control in-game.
